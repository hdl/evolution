Scripts, actions and workflows in this repository allow generating [Gource](https://gource.io/) videos of multiple
(optionally) combined git repositories.

Given a YAML and optionally a `.mailmap`, all the repositories are cloned using git and the logs are extracted using gource.
Logs and author lists are uploaded as an artifact.

Then, logs are combined according to the hierarchy specified in the *tree* field of the job, and a video is generated by
running gource on `xvfb-run` and piping the output to `ffmpeg`.
Moreover, a `.jpg` of the last half second is captured.
The video and the frame capture are uploaded as an artifact.
